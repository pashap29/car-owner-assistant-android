# Release Checklist

## Product Scope
- Confirm release scope matches approved MVP docs.
- Confirm no undocumented scope changes.

## Android Config
- Finalize app ID and versioning.
- Validate signing config.
- Confirm SDK targets.

## Privacy and Compliance
- Audit permissions and in-app rationale.
- Verify privacy policy and data-handling statements.

## Quality Gates
- Release build succeeds.
- Required tests/lint pass.
- Core manual smoke checks pass.

## Data Safety
- Migration paths validated.
- Backup/restore smoke test on clean install.
- Mileage rules regression checklist passed.

## Rollout
- Crash monitoring configured.
- Rollout and rollback plan defined.
