# Definition of Done

## Applies To
All documentation and implementation tasks in this repository.

## Core Criteria
- Scope aligns with plan and domain rules.
- Relevant docs updated and consistent.
- Risks and assumptions documented.
- Verification steps executed and reported.

## Policy-Consistency Criteria (Must Hold)
- Verified mileage policy matches resolved PRD/domain rules exactly.
- Mileage anomaly thresholds and conflict rules are unchanged unless explicitly re-approved.
- Statistics card thresholds and empty-state behavior are enforced.
- Backup restore remains safe replace with automatic pre-restore snapshot in MVP.
- Reminder cadence behavior matches first-car/first-mileage inactivity rules.

## For Implementation Tasks
- Build passes.
- Required tests pass.
- Lint/static checks pass or exceptions are justified.
- Offline behavior of changed core flows is validated.

## Closure Output
- What changed
- Files changed
- Verification performed
- Remaining risks/open questions
